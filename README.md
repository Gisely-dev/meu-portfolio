# Portfólio Pessoal

Meu portfólio desenvolvido para apresentar minhas habilidades, projetos e experiências na área de Desenvolvimento de Software.

Além de um design moderno e responsivo, o projeto conta com integração a um chatbot utilizando API, permitindo uma experiência mais interativa para os visitantes.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- API de Chatbot

## Funcionalidades

- Página inicial responsiva
- Apresentação profissional
- Seção de projetos
- Informações de contato
- Chatbot integrado por API
- Comunicação segura entre frontend e backend

## Instalação

Clone o repositório:

```bash
git clone https://github.com/Gisely-dev/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Crie um arquivo `.env` baseado no `.env.example`.

Exemplo:

```env
API_KEY=sua_chave_aqui
PORT=3000
```

Inicie o servidor:

```bash
node server.js
```

ou

```bash
npm start
```

Depois abra o navegador em:

```
http://localhost:3000
```

## Segurança

As chaves da API não são armazenadas no repositório.

Elas são carregadas através de variáveis de ambiente utilizando o arquivo `.env`, que está listado no `.gitignore`.
